# Privacy Notice

They Come At Night is a single-player game. It does not transmit any data
over the network.

## What the game stores locally

All data is written to your platform's standard user-data folder (`user://`
in Godot terms — typically `~/.local/share/godot/app_userdata/They Come At Night/`
on Linux, `%APPDATA%/Godot/app_userdata/They Come At Night/` on Windows,
`~/Library/Application Support/Godot/app_userdata/They Come At Night/` on macOS,
or browser IndexedDB on the web build).

| File | Purpose |
|---|---|
| `settings.cfg` | Audio volumes, display, accessibility, gameplay defaults |
| `save.json` | Current run state (one slot) |
| `crash.log` | Last unhandled error, if any (purely local; never transmitted) |
| `screenshots/*.png` | Screenshots you capture with F12 |

You can wipe all stored data by deleting the folder above. The game neither
collects nor transmits telemetry. The credits screen lists every bundled
third-party asset and its license.

## Content warning

The game depicts a zombie apocalypse with themes of death, betrayal,
cannibalism, infection, hopelessness, and the loss of children. Events
contain occasional mild profanity and references to violence. There are
no explicit graphics — this is a 32×32 grid game — but tone is dark.

If those themes are not for you, the game is not for you.
